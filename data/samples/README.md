# data/samples

Diretorio de trabalho para artefatos analisados.

**Nada aqui e versionado.** O `.gitignore` bloqueia binarios.
Para referenciar uma amostra publicamente, registre apenas o **hash**
(SHA256) e a fonte (MalwareBazaar, tria.ge), nunca o arquivo.

Exemplo de registro:

| SHA256 | Familia | Fonte | Data |
|--------|---------|-------|------|
| `44d88612fea8a8f36de82e1278abb02f` (EICAR, MD5) | test-file | eicar.org | - |
